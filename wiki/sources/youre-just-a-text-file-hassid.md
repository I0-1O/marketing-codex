# I Can Be You — You're Just a Text File

## Synopsis

[[ruben-hassid]] argues that an individual's voice, taste, and decision-making patterns can be reduced to a single 2,000–5,000 token markdown file. Hand that file to Claude (or any frontier LLM) and the model writes, decides, and refuses things the way you would. The provocation: *"You're just a text file."*

The methodology is a two-step process — a structured 100-question interview across seven categories, then compression into a portable markdown file. The author claims the full setup takes ~2 hours (90 minutes with voice dictation) and the resulting file works across Claude, ChatGPT, Gemini, and Grok without modification.

## Key Claims

- **Voice is extractable.** Patterns in someone's writing are identifiable, finite, and replicable — not mystical.
- **Portability beats platform.** A markdown file moves between AI tools; prompt-engineered workflows don't.
- **Taste documentation > algorithmic delegation.** You preserve editorial control by writing down what you reject, not by handing decisions to the model.
- **The bottleneck is you.** As models advance, the human who hasn't been "compressed" becomes the rate-limiter on their own output.

## The Two-Step Process

1. **Interview phase** — 100 targeted questions across seven categories
2. **Compression phase** — distill responses into a 2,000–5,000 token markdown file optimized for AI consumption

## Seven Interview Categories

1. Contrarian beliefs and unconventional takes
2. Writing mechanics and sentence structure preferences
3. Aesthetic dislikes in others' writing
4. Voice and personality expression
5. Structural preferences
6. Hard refusals (what you won't write, won't say, won't do)
7. Trust / distrust signals (red flags)

See [[voice-as-text-file]] for the concept page.

## Recommended Stack

- Claude with Cowork integration + Opus 4.7 + Extended Thinking
- Wispr Flow (voice-to-text) for honest, fast answers during the interview
- Obsidian for sustainable file editing with sync

## Anticipated Objections (and Hassid's Counters)

- *"This reduces me to a checklist."* → Your patterns *are* finite; documenting them doesn't shrink you, it makes you portable.
- *"I'd need months of introspection."* → Structured questions surface taste faster than open-ended reflection.
- *"My identity depends on mystique."* → Mystique doesn't scale; documented taste does.
- *"I'm uncomfortable committing to explicit refusals."* → The discomfort is the signal; that's where the voice lives.
